A simple web project created for the C-DAC PG-DBDA Git and AWS lab.

## Technologies
- HTML
- CSS
- JavaScript
- Git & GitHub
- AWS EC2 / S3

## Features
- Course module display

- Light/Dark mode
- Project contributors
- AWS deployment detection
